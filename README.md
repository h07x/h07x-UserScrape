- 📅 Account creation date, when available.

- 📝 Public Gists.
- 🔗 Public social links.
- 🌐 Blog or website.
- 📄 Public profile biography.

🚀 Usage

Run the program:

python axomgithubscrape.py

Choose option "1" and enter the GitHub username you want to look up.
